# Test the SafeAgent n8n template

Do this only after the n8n community node is approved and installed.

## 1. Import the template

Import:

`stop-duplicate-webhook-side-effects.json`

## 2. Activate the workflow

Copy the production webhook URL generated by n8n.

## 3. Send the first request

Use this JSON body:

```json
{
  "event_id": "order-12345",
  "amount": 100,
  "customer_id": "customer-42"
}
```

Expected decision: `PROCEED`

The execution should enter **Your Side Effect**, then **SafeAgent Settle**.

## 4. Send the exact same event again

Send the identical `event_id`.

Expected decision: `SKIP`

The second execution must route directly to **SKIP Response** and must not enter **Your Side Effect**.

## 5. Screenshot the proof

Capture:

- workflow canvas
- first run with PROCEED path
- duplicate run with SKIP path

Do not modify or republish the node package to perform this test.

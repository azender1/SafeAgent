# Agreed scope language

## Permitted wording after a successful independently operated run

One correctly bound FlowSignal-permitted action produced one confirmed Stripe
Test Mode payment, and reuse of the bound SafeAgent dispatch permit was blocked
on the tested gateway-controlled path.

- independent certification;
- production settlement;
- alternate-route closure;
- deployment-wide non-bypassability;
- production key isolation;
- distributed atomicity; or
- broader validation of either system.

The operator running the fixture and both maintainers should agree final wording
before characterising or publishing the result.

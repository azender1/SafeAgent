## Product description
SafeAgent is an execution-integrity layer for consequential AI-agent and workflow actions. It claims a logical action before execution, suppresses duplicate/replayed attempts, preserves unresolved outcomes after timeout or lost acknowledgement, and records durable receipts that can be reconciled against external provider evidence.

## Integration / use case
The proposed integration would connect Dynatrace autonomous operations or remediation workflows to SafeAgent before consequential external actions. The goal is to prevent a second external side effect when an agent or workflow retries after an ambiguous outcome, and to expose durable execution state and reconciliation evidence back into the Dynatrace operational view.

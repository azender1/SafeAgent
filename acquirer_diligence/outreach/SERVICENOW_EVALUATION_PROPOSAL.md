## Subject

Evaluation proposal: external-action settlement control for autonomous work

## Draft

ServiceNow is building governed autonomous work with deterministic outcomes, traceability, and enterprise control. SafeAgent addresses a specific boundary that may sit below those controls: an external action is permitted and completes, but the acknowledgement is lost before the workflow can durably record the result.

SafeAgent is an execution-integrity layer built for that uncertainty. It claims before dispatch, binds settlement to a one-use capability, blocks replay/duplicate execution, preserves unresolved state, and reconciles observed external outcomes through a read-only Control layer.

We are not proposing another agent framework or replacing ServiceNow workflow controls. We are asking whether this consequence-integrity primitive fills a real gap in Autonomous Workforce / AI Control Tower, or whether ServiceNow already guarantees the same behavior natively.

A bounded proof-of-value can use one synthetic or jointly selected external-action pattern with explicit pass/fail criteria.

We can provide the public implementation, production-hardening evidence, Control v15 test/mutation results, and independent EC-009 review material.

Please route this to the product or strategic owner responsible for autonomous execution reliability if appropriate.

\# Execution Guard Use Cases



\## Payments

Prevent duplicate charges when the agent or system retries under uncertainty.



\## Emails

Prevent duplicate outbound emails caused by retries or timeouts.



\## Trades

Prevent duplicate order submission and execution-state mismatches.



\## External API Mutations

Prevent repeated writes to third-party systems.



\## Database Writes

Prevent duplicate inserts or repeated transactional side effects.



\## Multi-Tool Agent Flows

Use correlation IDs across composed tool boundaries while keeping execution guards at each side-effect boundary.
